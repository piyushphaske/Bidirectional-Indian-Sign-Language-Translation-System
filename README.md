# Hand Sign Recognition Project

This project implements a hand sign recognition and translation system using YOLO, MediaPipe, and various NLP tools. It provides code, sample datasets, pre-trained models, and output examples to help you train, test, and deploy hand sign recognition models with a web interface.

## Project Structure

- `app.py`  
  Main application file. Likely runs the web server (Flask) and serves the user interface for hand sign recognition and translation.

- `og_code.py`  
  Main Python script for hand sign recognition, including model loading, inference, and possibly training routines.

- `og_code.ipynb`  
  Jupyter notebook version of the main code, useful for step-by-step exploration and experimentation.

- `requirements.txt`  
  Lists all Python dependencies required to run the project. Install with `pip install -r requirements.txt`.

- `Output_images/`  
  Contains output images generated by the model, such as predictions or visualizations.

- `output_video/`  
  Contains output videos generated by the application.

- `single_photo_dataset/`  
  Sample dataset organized by class (0-9, A-Z), used for training or testing the model.

- `static/`  
  Static files for the web interface (CSS, JS, and media files).

- `templates/`  
  HTML templates for the Flask web application.

- `train/` and `train5/`  
  Training results, images, labels, model weights, and evaluation metrics.

- `youtube_dataset/`  
  Additional dataset folders for extended vocabulary or training.

- `last.pt`  
  Pre-trained model weights (PyTorch format) used for inference or further training.

- `Final Code with GUI.ipynb`, `handsign_training_using Yolo And mediapipe.ipynb`  
  Additional Jupyter notebooks for GUI and training workflows.

- `stored_text.txt`  
  Stores recognized or translated text output.

- `system_evaluation_metrics.png`, `translation_visualizations.png`  
  Visualizations and evaluation metrics for the system.

- `youtube_hyperlinks.xlsx`  
  Excel file with YouTube links, possibly for dataset or reference.

- `example_video.mp4`, `translation_animation.mp4`  
  Example and demo videos.

## Setup Instructions

1. **Clone the repository**
   ```powershell
   git clone <repo-url>
   cd NLP_mini_Project
   ```

2. **Install dependencies**
   ```powershell
   pip install -r requirements.txt
   ```

3. **Prepare the dataset**
   The `single_photo_dataset/` folder contains sample images for each class. You can add more images or use your own dataset in the same structure.

4. **Run the application**
   ```powershell
   python app.py
   ```
   This will start the Flask web server. Open your browser and go to `http://localhost:5000` to use the interface.

5. **View results**
   Output images and videos will be saved in the `Output_images/` and `output_video/` folders.

## Notes

- The `last.pt` file is required for inference. If missing, you will need to train the model first.
- The `requirements.txt` file lists all necessary dependencies.
- The `Output_images/`, `output_video/`, and `single_photo_dataset/` folders are essential for running and testing the project.
- For training or extending the dataset, refer to the `train/`, `train5/`, and `youtube_dataset/` folders.
